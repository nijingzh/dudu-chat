# duduchat — iOS 双人实时聊天 App 设计方案

> Web 技术 + Capacitor 打包 iOS App | Liquid Glass 玻璃美学 + 甜蜜浪漫 + 极致触觉反馈

---

## 一、项目概述

| 项目 | 内容 |
|------|------|
| **应用名** | duduchat |
| **定位** | 专属于两个人的甜蜜私密聊天空间 |
| **平台** | iOS（iPhone，竖屏） |
| **开发方式** | React + Capacitor 打包为 iOS App |
| **开发者环境** | Windows 开发 + GitHub Actions 云端构建 |
| **用户** | 你 + 女朋友（双人专属） |

## 二、技术栈

| MongoDB | 消息存储 / 用户数据 |
| Redis | 在线状态缓存 |
| JWT | 认证鉴权 |

## 三、设计系统 — Liquid Glass 甜蜜风

### 3.1 色彩

**主渐变（背景氛围），135deg 方向：**

| 起始 | 结束 | 描述 |
|------|------|------|
| `#FFB6C1` 浅粉 | `#E8A0BF` 淡紫粉 | 主渐变 |
| `#F7CEC5` 蜜桃 | `#F8E8EE` 奶白粉 | 柔和渐变 |
| `#D4A5FF` 梦幻紫 | `#FFB3D9` 樱花粉 | 梦幻渐变 |

**玻璃卡片：**

| 属性 | 值 |
|------|-----|
| 背景 | `rgba(255,255,255, 0.18~0.35)` |
| 边框 | `1px solid rgba(255,255,255, 0.45)` |
| 模糊 | `backdrop-filter: blur(24px) saturate(180%)` |
| 阴影 | `0 8px 32px rgba(255,182,193, 0.25)` |

**消息气泡：**
- 自己：渐变粉 `#FF8FAB → #FF6B8A`
- 对方：半透明白 `rgba(255,255,255, 0.55)` + 彩色描边

**辅助色：**

| 颜色 | 色值 | 用途 |
|------|------|------|
| 金色 | `#FFD700` | 装饰 |
| 樱花白 | `#FFF5F7` | 背景 |
| 薰衣草紫 | `#C8A2FF` | 强调 |
| 薄荷绿 | `#A8E6CF` | 在线状态 |
| 珊瑚红 | `#FF6B6B` | 未读/心跳 |

### 3.2 字体

| 场景 | 字体 |
|------|------|
| 标题 | Quicksand（圆润可爱） |
| 正文/气泡 | Noto Sans SC / 系统字体 |
| 数字（计数器） | Comfortaa |

### 3.3 Liquid Glass 组件规范

**GlassCard（玻璃卡片）**
- 背景 `rgba(255,255,255, 0.22)`，模糊 `blur(28px)`，圆角 `24px`
- 边框 `1px rgba(255,255,255, 0.35)`，阴影粉色柔光

**GlassButton（玻璃按钮）**
- 圆角 `20px`，渐变叠加，按压 `scale(0.96)`

**GlassNav（底部导航）**
- 模糊 `blur(32px)`，顶部渐变高光，圆角 `28px`

### 3.4 触觉反馈（iOS Haptics）

| 交互 | 震动类型 | 强度 |
|------|---------|------|
| 发送消息 | Impact | Light |
| 收到消息 | Impact | Medium |
| 点赞/心形 | Notification | Success |
| 长按消息 | Selection | — |
| 滑动切换 | Selection | 轻微 |
| 特殊表情 | Impact | Heavy |
| 甜蜜时刻 | Notification | Success × 2 |
| 页面切换 | Selection | 轻 |

## 四、功能架构

### 4.1 全景

```
duduchat
│

│   │   └── 🎉 庆祝特效（烟花）
│   ├── 消息表情回应（长按加 emoji）
│   ├── 正在输入… 动画
│   ├── 已读回执

│   ├── 💝 写封蜜语（情书/便签）
│   ├── 💌 慢递信（定时发送）
│   ├── 🎰 约会转盘（随机建议）

    ├── 新消息

    └── 纪念日提醒
```

### 4.2 核心交互

**发送消息：** 按下发送 → 轻震动 → 气泡飞入 → 发送成功 → 微放大 + 轻震动

**收到消息：** 到达 → 中震动 → 弹性入场（spring）→ 红点心跳

**长按消息：** 震动 → 反应表情条（💕😂😮😢👍🔥）→ 选中 → 成功震动 → 表情浮出

**表情回应：**
- 撒娇 → 气泡变大 + 粉色脉冲
- 想你 → 全屏飘落爱心
- 不开心 → 灰色调 + 雨滴
- 开心 → 烟花 + confetti

**甜蜜特效：** 背景飘浮粒子（💗🌟🌸✨）、心跳脉冲、全屏飘心动画

## 五、页面设计（8 页）

### 1. 启动/登录页
渐变粉紫背景 + 飘浮粒子 → 情侣头像 → 「duduchat」大标题 → 玻璃卡片输入邀请码 → 玻璃按钮进入 → 底部文案

### 2. 聊天主页（核心）
顶部玻璃导航（对方昵称 + 在线状态 + 在一起天数）→ 消息气泡区（左白右粉）→ 长按反应 → 底部玻璃输入栏（文本/语音/图片/表情/发送）

### 3. 甜蜜时光页
大数字计数器（心跳动画）→ 纪念日倒计时卡片 → 今日心情打卡 → 爱情日记 → 照片墙（瀑布流）

### 4. 小惊喜页
写封蜜语 → 慢递信 → 约会转盘（随机转一转）→ 一起听歌 → 今日情话（可换）

### 5. 个人资料页
头像/昵称/签名 → 主题色 → 聊天背景 → 数据导出

### 6. 设置页
触觉反馈开关（发送/收到/特效）→ 通知开关 → 外观（粒子/气泡/心跳）→ 隐私（消息锁）

### 7. 消息详情页
全屏图片（可缩放）→ 语音播放（波形）→ 上下文预览

### 8. 纪念日管理页
纪念日列表 + 倒计时 → 添加/编辑/删除

## 七、开发路线

### Phase 1 — UI 前端

**Week 1：脚手架 + 设计系统**
- Vite + React + TS 项目初始化
- TailwindCSS 配置 Liquid Glass tokens
- GlassCard / GlassButton / GlassNav / GlassInput
- FloatingParticles 背景粒子
- useHaptics 触觉反馈 hook

**Week 2：核心页面**
- 登录页（邀请码 + 飘浮动画）
- 聊天页（气泡 + 输入栏 + 特效）
- 甜蜜时光页
- 小惊喜页

**Week 3：交互细节**
- 消息气泡动效（发送/接收/反应）
- 全屏特效（想你了/撒娇/庆祝）
- 页面转场动画
- 手势 + 触觉反馈
- 移动端适配优化

### Phase 2 — 后端 + 实时

**Week 4：后端**
- Express + Socket.io 服务
- MongoDB 消息存储
- JWT 认证
- 消息 API

**Week 5：实时功能**
- WebSocket 消息推送
- 在线状态 / 正在输入 / 已读回执
- 图片/语音上传
- iOS 推送通知（APNs）

### Phase 3 — 增值

**Week 6+：** 语音/视频通话、数据统计、正式发布

## 八、iOS 打包流程（Windows 开发）

```
Windows 写代码
     │
     ▼
git push → GitHub
     │
     ▼
GitHub Actions（macOS 云端）
  → npm run build
  → npx cap sync ios
  → xcodebuild archive
  → 导出 .ipa
     │
     ▼
上传 TestFlight
     │
     ▼
你和女朋友 iPhone 打开 TestFlight → 安装 🎉
```

**GitHub Actions 构建脚本要点：**
- `runs-on: macos-latest`
- 自动安装 Node → 构建前端 → 同步 Capacitor → xcodebuild → 上传 TestFlight
- 签名证书通过 GitHub Secrets 配置（免费 Apple 账号即可）
