## 二、路线裁决与技术校对

### 1. 分发：免费账号 + AltStore 数据线签名（裁决 B，已核实可行）

硬限制（Apple 免费账号政策，已查证 2026 年现状）：
- 描述文件 **7 天过期**，到期 App 打不开，插线刷新即恢复；
- 同时最多 **3 个侧载 App**（duduchat 只占 1 个槽位，两台手机装同一个 App 不多占）；
- 每 7 天滚动最多注册约 10 个 App ID（本项目只用 1 个，无所谓）；
- iOS 16+ 需开「开发者模式」（设置 → 隐私与安全性 → 开发者模式）；
- 首次注册设备 Apple 侧处理可能要 1–3 天，首次装不上属正常。

运维口径：
- Windows 装 **Apple 官网版 iTunes + iCloud**（微软商店版 AltServer 不认），防火墙放行 AltServer；
- 刷新方式两条：同 Wi-Fi 且 AltServer 在跑时自动刷；**数据线插电脑 → AltServer 刷新**（本方案主路径，每周一次，两台手机各自刷）；
- 忘了刷超 7 天 → App 打不开但**数据不丢**（同 bundle ID 覆盖重签安装，消息/日记都在），插线刷新即恢复；
- 备选 Plan B：SideStore（配对一次后手机端自刷、连电脑都省），AltStore 用得烦了可换，签名机制相同。

**打包链路随之简化（比设计方案原流程更省事）：**
```
Windows 写代码 → git push → GitHub Actions（macOS 云端）
  → npm run build → cap sync ios → xcodebuild 导出无签名 .ipa
  → 下载 .ipa 传到手机 → AltStore 用免费 Apple ID 重签名安装
  → 每周插线刷新一次 🎉
```
GitHub Actions 不再需要任何证书 Secrets（签名发生在 AltStore 侧），设计方案第八节的 TestFlight 流程作废，以此为准。

### 2. 「免费账号没有的东西」与 Phase 2 调整

免费账号**不能用 APNs 推送**（付费账号才有），设计方案 Phase 2 的「iOS 推送通知（APNs）」整项砍掉。调整后：

| 原设计 | 调整后 | 影响 |
|--------|--------|------|
| APNs 新消息推送 | **前台实时照旧**（Socket.io 秒推）；回前台重连 + 拉离线消息补上 | 唯一损失：App 关着/后台挂起时收不到提醒 |
| 想你了提醒 / 纪念日提醒 | **本地通知**（UNUserNotificationCenter，无需付费账号，可离线预排） | 无影响，照常弹 |
| 每日情话 | 本地通知定时弹 + 打开 App 看全文 | 无影响 |
| 慢递信（定时发送） | 近似方案：信件到达时若对方在线 → 对方设备排一条本地通知到点响；不在线 → 下次打开 App 收信 + 立即弹提醒 | 时效略降，功能可用（此近似口径待复审） |
| 桌面图标角标 | App 内未读数（桌面角标需 push，做不了） | 视觉变化，仅此而已 |
| 已读回执 / 正在输入 / 在线状态 | **照常**（前台 WebSocket 功能） | 无影响 |

其余全部功能（文字/语音/图片/表情回应/撤回/消息特效/触觉反馈/甜蜜时光/小惊喜/照片墙/日记）纯本地渲染 + 普通 API，**与签名方式零关系，全部正常**。
工程上补三件事：断线重连 + 离线消息补偿（iOS 切后台约 30 秒挂起 socket，回前台重连是常态）；服务器侧留**推送抽象层**（接口预留，将来升级付费账号插回 APNs 不动架构）；触觉反馈不受影响。

### 3. 后端：另开美国服务器（裁决）
Node + Express + TS + Socket.io + MongoDB + Redis 常驻约 1GB 内存起，选 2C2G 起步的美国 VPS。已知代价：国内 → 美国 RTT 约 150–250ms，聊天消息能感到但可用；跨境链路偶发不稳，对策 = WSS 加密 + 断线重连做扎实 + 消息服务端兜底排序。若实际用下来延迟明显，Phase 2 再议中转方案，不预先加复杂度。接口一律 HTTPS（Let's Encrypt 免费证书），Capacitor 的 ATS 只认 HTTPS。

### 4. 邀请码（裁决通过）
两个固定邀请码各绑一个账号（你 / 女朋友），输对即登录，本地记住会话；Phase 2 换 JWT，邀请码只做注册绑定。不搞找回密码、第三方登录。

### 执行细节（我定，不占裁决）
- Tailwind v4 CSS-first（`@theme` 写 tokens，设计方案的 tailwind.config.js 是 v3 写法，token 值照抄 3.1–3.3）；
- 字体（Quicksand / Noto Sans SC / Comfortaa）走 Google Fonts；
- mock 数据 zustand + localStorage，Phase 2 只换数据层，UI 不动。
